## DEC-13-001 — Execution placement, skew and bounded work

decision · domain 13 · [DEC-13-001 — Execution placement, skew and bounded work](../../decisions/execution-strategy.md)

Choose a bounded single-process, database/vectorized, or partitioned execution plan for the same declared ER semantics before changing retrieval budgets. Distinguish physical tiling that preserves comparisons from logical truncation that changes the population. Requires measured workload tails, resource limits, dependency versions and output-equivalence contracts. Compare total index, shuffle, comparison, resolution and recovery costs; distributed execution is not automatically faster, more complete or reproducible.

## SOL-13-001 — Skew-aware bounded execution with complete pair coverage

solution · domain 13 · [SOL-13-001 — Skew-aware bounded execution with complete pair coverage](../../solutions/scalability/skew-aware-execution.md)

Stream or tile candidate work while retaining declared eligibility, stable pair identity and complete comparison coverage. Profile hot blocks and expensive feature routes, choose resident-data batching before optional distribution, and reconcile retries and global resolution. Requires task coverage manifests, versioned indexes and resource accounting. Tiling bounds memory, not inherent pair count; caps, timeouts and incomplete tasks must remain distinguishable from valid non-matches and from equivalent physical optimization.
