# Verified bibliography

Eight references support the pilot; their numbers are stable ledger IDs, not an importance ranking. Failed exploratory IDs 6 and 8 are excluded. Full texts were retrieved for seven references; reference 9 was verified from the publisher abstract only. The repository contains bibliographic/provenance records, not copies of copyrighted papers. See [research notes](research-notes.md), [retrieval status](retrieval-status.json), [retrieval provenance](retrieval-provenance.json), and [evidence policy](evidence-policy.md).

## Reuse discipline
A verified title or mathematical model is not a measured gain on an unfamiliar project. Keep each cited claim within source scope; architecture contracts, suggested experiments and hypothetical scenarios are Atlas synthesis. Literature classification can guide which alternatives exist; primary mechanism/guarantee checks are required before expanding detailed methods. No performance numbers have been copied into this pilot as universal forecasts.
