# Frozen independent agent-utility protocol (cohort AU-v1)

Freeze inputs, evaluator-only keys/rubric, prompt, settings, schemas, this protocol and original baseline manifest before any tested-agent result or coverage-card writing. `freeze-manifest.json` is write-once and every command verifies it. Its digest is an external anchor; do not regenerate it to bless changed content. Harness fixes may change harness hash, but require rerunning both arms and documenting the fix without modifying frozen artifacts. Schema/protocol changes require a separately named cohort. No post-hoc answer-key tuning, even for unexpected defensible answers; record evaluator disagreement instead.

## Independence and comparison
The benchmark author is not an evaluator and is not a tested agent. Parent selects a real adapter/model before model runs; no credentials are accepted by this package. A model run uses a newly spawned command process and new model conversation for every scenario. Adapter must declare `fresh_context=true`, `broker_only=true`, its identity, and the exact settings hash before reads/final output. These attestations are provenance, not an OS sandbox: subprocesses can access the host. The operator MUST run only a trusted adapter that gives the model no tools except this JSONL broker; use an OS/container sandbox for untrusted code. Harness does not certify process isolation beyond fresh spawn/cwd and controlled protocol context. Never pass benchmark directory, source-repo path, keys or rubric in the start message/environment. Strip inherited environment except basic locale/PATH/HOME/TMPDIR; HOME/TMPDIR point to a fresh temporary working directory. Credentials must be handled externally by an operator-controlled adapter, not this harness. Hidden memory, autonomous shell tools, direct corpus reads or additional retrieval violate eligibility.

Prepare v1 from the saved full baseline snapshot, verifying every hash in `baseline/atlas-v1-baseline-hashes.json` and no extra files. Prepare v1.1 from the finished working tree, never during edits. Both use exactly the same allowlist, generated L0 metadata, frozen prompt, scenarios, budgets, layer availability, settings and adapter command. Raw CATALOG is intentionally NOT packaged: it contains scenario/coverage pointers and long version-specific summaries. L0 is generated identically from card ID/title/type/domain/summary, concise applicability at 180 characters, canonical path. L1 includes taxonomy/domain maps and architecture dimensions/module contracts; L2 includes full decision/solution/architecture/evaluation/hypothesis cards; L3 includes deep-dives and only bibliography/evidence-policy references. Allowlisted directories must contain genuine corpus cards, not benchmark answers. All `guides/` (including scenario-stress-tests), `validation/`, `tests/`, `tools/`, `dev_docs/`, templates, implementation plans, research answers/reviews/opportunities, coverage matrices and change logs are excluded. Explicitly allowed research/hypotheses cards are the only research material. Symlinks are rejected. Layer filtering applies identically to both arms; changing budgets/layers/settings after seeing results requires a new cohort.

A corpus manifest records copied original hashes, generated-index hash, layer and bytes; source location stays operator-only. Its contents are verified before each run. No-Atlas is an optional arm with an empty inventory and same remaining settings. A declared missing/no command produces `unexecuted`; prepare/dry-run produces `prepared`; timeout, malformed protocol, budget violation, nonzero exit or missing attestation/final yields `failed`. Never interpret fixture responses or dry-run as independent model results. Keep all attempted runs and failures; pre-register scenario order, repetitions (default one each), adapter identity/model and exclusions before running. Run v1/v1.1 in counterbalanced order AU-01 v1 then v1.1, AU-02 reverse, alternating onward; record actual dates and invocation. Do not selectively omit failed scenarios or cherry-pick seeds. One seed is exploratory, not a significance claim.

## Broker and hard budgets
Agent-facing JSONL initial message: `type=start`, protocol_version, scenario object, frozen prompt, settings, settings_sha256, inventory [{path,layer,bytes}], read_file tool description. No keys, rubric, expected findings, protocol prose, corpus labels/version, source paths or benchmark code. Do not include read-budget scoring anchors. Adapter stdout is exclusively protocol. Adapter first writes `type=ready`, `identity`, `fresh_context=true`, `broker_only=true`, `settings_sha256` matching initial message. Then it writes requests `{"type":"read_file","request_id":"r1","path":"...","offset":0,"length":8000}`. Offset/length are Unicode characters (not tokens/bytes); bounds must be integers, offset >= 0 and 1 <= length <= max_chunk_chars. Broker returns `type=read_result`, matching request_id, path, content, error, remaining budgets. Paths must exactly exist in inventory; absolute paths, traversal, alternate separators and symlinks are denied. Repeated reads count in full; denied attempts are logged/count against attempts. Reads and content snippets, layer, offsets, hashes and cumulative counters are retained. Budget errors fail the run, rather than silently opening more context. Adapter writes `{"type":"final","text":"..."}` and exits zero. Any later stdout or nonzero exit fails. Wall timeout covers the full interaction; each line is bounded. Final and initial characters are bounded. Settings include model name, temperature, seed and model output-token cap; operator must fill model before run without changing frozen defaults by using a separate pinned execution-settings file applied identically to both arms. Harness validates its structure and budgets, records its hash; freeze that execution file externally before running. No tokenization dependency: measured context is Unicode characters plus adapter-reported model usage if independently recorded outside harness. Character limits are not token-equivalent.

## Scoring and provenance
A distinct blinded evaluator gets a neutral packet containing input, response, actual read snippets/logs, keys and rubric, and hashes. Packet excludes arm labels, source paths, author conclusions, run timestamps and aggregate scores. Evaluator identity/role, independence, blinding, conflicts, timestamp, run/corpus/settings/manifest digests must be declared. Output contains exactly eight dimension entries, each raw ordinal 0–3, rationale, verbatim response evidence quotes and/or omitted expected-finding IDs. No-Atlas retrieval is null with explicit not_applicable rationale. Corpus gaps do not automatically penalize the agent: honest identification with defensible reasoning can be good; fabricated missing cards cannot. Relevant retrieval is judged against available corpus and read content, not a fixed v1.1 ID list.

Keys enumerate central semantic findings and conditional critical-failure triggers, not an ideal prose answer. Trigger only when response actually endorses the failure, not when discussing a bad baseline diagnostically. Global fabrication and unauthorized irreversible action triggers also apply. Failures require exact quoted response evidence plus explanation. Harness checks IDs, quote membership, provenance and computes per-dimension caps deterministically; independent evaluator must verify the semantic findings and citation accuracy. Raw/effective scores remain separate; no aggregate, arbitrary weighted score or overall pass status. Unexecuted/failed/prepared runs are unscored. Score read logs and final entities/constraints, not keyword/card counts. A mechanically valid score is not proof of evaluator reliability. Have another independent evaluator adjudicate material disagreements if feasible; retain both, never overwrite.

Report paired per-scenario per-dimension vectors, critical failures, read characters/attempts, wall failures and missing evaluations; no improvement claim before actual model runs and independent scoring. No ER algorithms/data processing/training are part of this package. Benchmark scenarios are fictional test inputs, not empirical ER observations.
