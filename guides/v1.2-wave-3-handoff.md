## Scientific constraints to preserve

1. Canonical character equivalence is not identity; compatibility folding or dropping geographic/legal/series tokens can destroy decisive information.
2. Script is not language; aliases/derived forms/copies are not independent corroboration. A format/checksum pass is not authoritative identifier assignment or uniqueness.
3. MinHash collision/banding probabilities refer to a stated random set-similarity construction, not ER recall. Set-length filters use set cardinalities, not raw character lengths.
4. New candidates are not new true matches. Caps/filters change the admitted population and can invalidate score/calibration applicability; compare isolated stages and end-to-end effects separately.
5. FS manual specification remains credible; EM convergence is not identifiability or calibration. Pooled/context effects distinguish prevalence from field reliability, with independent source-slice evidence.
6. A true chain can have bridges and a dense wrong entity can have none. Graph topology/constraint consistency cannot certify population identity accuracy.
7. Must-link is transitive; cannot-link is not. Whole-cluster admissibility includes all restrictions, and a soft objective does not permit violation of externally mandatory constraints.
8. Persistent identity, membership versions and master attributes remain separate. Repair must honor history/authorization rather than assume the same final observations imply the same state.
