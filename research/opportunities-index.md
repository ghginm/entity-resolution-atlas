# Research opportunities retained from the drafts

This index preserves valuable ideas without generating unreviewed Solution Cards. Every row is an **unexpanded opportunity**, not a novelty claim, observed result or universal priority. Existing methods may motivate exploratory comparisons in a new context. Actual project errors, labels, privacy and budgets determine which experiment is worthwhile.

## Pilot hypotheses
- [HYP-06-001 — Frequency-aware evidence](hypotheses/frequency-aware-evidence.md): test whether frequency information adds useful distinction beyond similarity in a declared population.
- [HYP-07-001 — Contextual attribute reliability](hypotheses/contextual-reliability.md): test shared/field/source context under adequate labels and controls.
